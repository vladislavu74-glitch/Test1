# Job Monitor

Мониторинг вакансий на нескольких ресурсах (hh.ru по странам СНГ,
SuperJob, Habr Career, плюс расширяемые ATS/RSS-источники) с iOS-клиентом
и backend'ом, который ежедневно в 10:00 сканирует источники и присылает
письмо на `vladislav.u74@gmail.com`, если появились новые подходящие
вакансии.

## Состав репозитория

- **`backend/`** — Node.js + TypeScript сервис: REST API, планировщик
  (ежедневный скан в 10:00), коннекторы к источникам вакансий, отправка
  email. См. `backend/README.md`.
- **`ios/`** — SwiftUI-приложение (iOS 16+), тонкий клиент поверх API
  backend'а: список вакансий с сортировкой по свежести и скрытием/показом
  записей, выбор источников для мониторинга, ведение своего списка
  названий должностей с выбором нужных для поиска, настройка остальных
  критериев. См. `ios/README.md` — там же пошаговая инструкция по сборке
  и установке на физический iPhone через Xcode.

## С чего начать

1. Поднимите backend (`backend/README.md`): установить зависимости,
   заполнить `.env` (ключ Resend для писем, при желании ключ SuperJob API),
   накатить миграции, засеять источники, запустить.
2. Соберите и установите iOS-приложение на свой iPhone через Xcode
   (`ios/README.md`) и укажите в Настройках адрес backend'а и API-токен.
3. Во вкладке «Должности» добавьте и выберите названия вакансий, которые
   ищете; во вкладке «Источники» включите нужные ресурсы; во вкладке
   «Критерии» задайте локацию/зарплату/удалёнку.
4. Нажмите «Искать сейчас», чтобы проверить, что всё работает, и
   разверните backend на постоянно работающем сервере, чтобы ежедневный
   скан в 10:00 и email-уведомления срабатывали и когда приложение закрыто.
