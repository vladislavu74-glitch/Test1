# Job Monitor

Поиск и мониторинг вакансий по ресурсам найма (карьерные страницы
работодателей, Telegram-каналы, кадровые агентства, профессиональные
сообщества), которые находит и верифицирует ИИ-агент, с iOS-клиентом и
backend'ом, который ежедневно в 10:00 сканирует подтверждённые ресурсы и
присылает письмо на `vladislav.u74@gmail.com`, если появились новые
подходящие вакансии.

## Состав репозитория

- **`backend/`** — Node.js + TypeScript сервис: REST API, планировщик
  (ежедневный скан в 10:00), ИИ-агент поиска и верификации ресурсов найма
  (Claude + `web_search`/`web_fetch`), коннекторы для скана вакансий,
  отправка email. См. `backend/README.md`.
- **`ios/`** — SwiftUI-приложение (iOS 16+), тонкий клиент поверх API
  backend'а: список вакансий с сортировкой по свежести и скрытием/показом
  записей, поиск и просмотр ресурсов найма (с параметрами, статус-баром и
  остановкой поиска), ведение своего списка названий должностей, настройка
  остальных критериев. См. `ios/README.md` — там же пошаговая инструкция по
  сборке и установке на физический iPhone через Xcode.

## С чего начать

1. Поднимите backend (`backend/README.md`): установить зависимости,
   заполнить `.env` (ключ Anthropic для поиска ресурсов, ключ Resend для
   писем), накатить миграции, запустить.
2. Соберите и установите iOS-приложение на свой iPhone через Xcode
   (`ios/README.md`) и укажите в Настройках адрес backend'а и API-токен.
3. Во вкладке «Ресурсы найма» задайте параметры (география, специализация,
   категории) и запустите поиск — найденные и подтверждённые ресурсы сразу
   становятся источниками для скана вакансий.
4. Во вкладке «Должности» добавьте и выберите названия вакансий, которые
   ищете; во вкладке «Критерии» задайте локацию.
5. Нажмите «Искать сейчас» на вкладке «Вакансии», чтобы проверить, что всё
   работает, и разверните backend на постоянно работающем сервере, чтобы
   ежедневный скан в 10:00 и email-уведомления срабатывали и когда
   приложение закрыто.
